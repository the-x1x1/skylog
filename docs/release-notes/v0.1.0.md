First release of a private, local-first journal for your ChatGPT and Claude conversations. Import a data export and each conversation becomes a journal entry: its images up front, a short summary, key decisions and next steps linked to the messages they came from, extracted lists and highlights, and the full transcript.

Nothing leaves your computer unless you turn on summaries with a cloud model. There's no account, sync or telemetry.

## Download

| File | For |
| --- | --- |
| `Skylog-0.1.0-windows-x64.exe` | Windows 10 and 11 (64-bit). Double-click to run. |
| `Skylog-0.1.0.html` | Any computer: open it in Chrome or Edge. Nothing to install. Summaries through a cloud model aren't available in this version; Ollama works. |
| `SHA256SUMS.txt` | Checksums for both files. |

### Running the Windows program

1. Download the `.exe` and double-click it.
2. Windows may say **"Windows protected your PC"** because the program isn't code-signed yet. Choose **More info**, then **Run anyway**.
3. A small window opens and your journal opens in your browser at `http://localhost:4173`. Keep the window open while you use the journal; close it to quit.

Your journal is saved in your browser, not inside the program. It's still there the next time you start the program, including after you replace the `.exe` with a newer version. To keep a copy of the journal, use **Settings → Back up journal**. Clearing that browser's site data for `localhost` deletes the journal, so back up first.

### Turning on summaries (optional)

Importing, browsing and search all work without AI. To add summaries, pick one of these:

- **Anthropic or OpenAI:** put a file named `.env.local` in the same folder as the `.exe`, containing `ANTHROPIC_API_KEY=sk-ant-...` or `OPENAI_API_KEY=sk-...` with `LLM_VENDOR=openai`. Restart the program, then choose **Local server (Anthropic or OpenAI)** in **Settings → Summaries**. In Notepad, set **Save as type** to **All files** so the file isn't saved as `.env.local.txt`.
- **Ollama:** run [Ollama](https://ollama.com) with a model pulled, then choose **Ollama on this device** in **Settings → Summaries**. Nothing leaves your computer.

## What's in 0.1.0

- **Import**
  - ChatGPT and Claude export `.zip` files, detected automatically.
  - A preview before anything is saved: conversation count, how many are already in your journal, images, date range and warnings.
  - Imports run in the background with progress in the sidebar and can be cancelled.
  - Re-importing updates changed conversations and keeps your summaries and edits.
  - Every import produces a report.
- **Entries**
  - The image gallery comes first, with a lightbox and swipe on mobile.
  - A summary, key decisions and next steps that link back to their source messages, extracted lists and highlights.
  - The transcript is collapsed until you open it, and you can search within it.
  - You can edit the title, subtitle, tags, collection and next steps, and export an entry as Markdown or JSON.
- **Search:** press Ctrl+K from anywhere. Results are grouped, and you can filter by source, collection, tag and date. Each result links to the exact message.
- **Summaries:** optional, through Anthropic, OpenAI or Ollama. Long conversations are split into chunks and the results merged. Every summary item links back to its source messages.
- **Your data:** back up and restore, request persistent storage, delete sample data or everything.
- **Design and access:** light and dark themes, a mobile layout, and keyboard and screen-reader support.

## Known limitations

- Claude exports don't include images you uploaded, so they show as labelled placeholders.
- A `conversations.json` larger than 500 MB can't be imported.
- Summaries have been tested against simulated Anthropic, OpenAI and Ollama responses, but not yet against the live services.
- The Windows program isn't code-signed yet, so SmartScreen shows a warning.
- There's no macOS or Linux program yet. Use the `.html` file, or run from source (see the README).
